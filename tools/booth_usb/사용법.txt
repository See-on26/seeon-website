SEEON 부스 — 일반객 체험 띄우기
만든 날 {{BUILD}}

이 폴더 하나로 노트북에서 일반객 체험이 돌아가요. 인터넷이 없어도 되고, 따로 설치할 것도 없어요.
Windows 10·11 노트북이면 되고, Chrome 이 있으면 Chrome 으로, 없으면 Edge 로 띄워요.

폴더 안
  시작.bat              체험을 켜요 (더블클릭)
  끝내기.bat            체험 화면과 서버를 꺼요
  자동 시작 켜기.bat    노트북에 로그인하면 체험이 저절로 켜지게 해요
  자동 시작 끄기.bat    위 설정을 꺼요
  server\               체험 서버 (건드리지 마세요)
  site\                 체험 사이트 (건드리지 마세요)


1. 노트북에 옮기기 (노트북마다 한 번)
-------------------------------------------
USB 로 옮길 때
- USB 의 seeon-booth-usb 폴더를 통째로 노트북에 복사하세요. 예: 바탕 화면, 또는 C:\seeon-booth-usb
- USB 에서 바로 켜도 돌아가요. 그래도 하루 종일 돌릴 거라면 노트북에 복사해 두는 편이 안전해요.
  USB 가 빠지거나 느려져도 체험이 멈추지 않아요.
- 폴더 안의 파일 이름과 위치는 바꾸지 마세요. 폴더째 옮기는 건 괜찮아요.

구글 드라이브·메일로 받을 때 (seeon-booth-usb.zip)
- 폴더 대신 seeon-booth-usb.zip 파일 하나를 올리고 받으세요.
- 받을 때 브라우저가 '자주 다운로드되는 파일이 아니에요' 같은 경고를 띄우면 [유지] 를 누르세요.
- 받은 zip 을 우클릭 → 속성 → 아래쪽 '차단 해제' 에 체크 → 확인.
  깜빡해도 괜찮아요. 시작.bat 을 처음 누를 때 보안 경고가 한 번 뜨는데, [실행] 을 누르면 다음부터는 안 떠요.
- zip 을 우클릭 → [모두 압축 풀기]. 풀린 폴더 안에 seeon-booth-usb 폴더가 한 번 더 들어 있어요.
  그 seeon-booth-usb 폴더를 바탕 화면이나 C:\ 로 옮겨 두면 찾기 쉬워요.
- zip 을 연 채로 안의 시작.bat 을 누르면 켜지지 않아요. 꼭 압축을 푼 폴더에서 누르세요.


2. 켜기
-------------------------------------------
- 시작.bat 을 더블클릭하세요.
- 검은 창(SEEON 부스 서버)이 뜨고, 곧 체험 화면이 전체 화면으로 떠요. 검은 창은 작업 표시줄로 내려가요.
- 검은 창은 체험 서버예요. 닫으면 체험이 멈추니 그대로 두세요.
- 체험 화면이 이미 떠 있을 때 시작.bat 을 다시 누르면 화면만 새로 띄워요.
- 헤드폰을 쓰고 [체험 시작하기] 를 눌러 시온 STORY 소리가 들리는지 확인하세요.


3. 끄기
-------------------------------------------
- 체험 화면에서 Alt+F4 를 누르면 화면이 닫혀요.
- 서버까지 끄려면 끝내기.bat 을 더블클릭하세요. 작업 표시줄의 검은 창(SEEON 부스 서버)을 닫아도 돼요.
- 끝내기.bat 은 체험 화면과 서버를 한 번에 꺼요. 평소 쓰는 Chrome·Edge 창은 건드리지 않아요.
- Alt+F4 가 안 먹으면 Windows 키를 눌러 작업 표시줄을 띄운 뒤 끝내기.bat 을 실행하세요.


4. STAFF 조작 (체험 화면에서)
-------------------------------------------
- Esc 를 2초 동안 꾹 누르기  → 처음 화면으로 돌아가요.
  처음 누를 때는 전체 화면만 풀리고 그대로일 수 있어요. 손을 뗐다가 한 번 더 2초 누르세요.
- S                          → 지금 단계를 건너뛰어요(점검용).
  건너뛰고 끝까지 가면 마지막 화면에 간식 안내가 뜨지 않아요.
- 마지막 화면의 [처음으로]   → 1초 동안 길게 누르세요.
- 화면이 멈추거나 이상하면 F5 (새로고침). 그래도 안 되면 시작.bat 을 다시 더블클릭하세요.


5. (선택) 노트북을 켜면 저절로 시작하기
-------------------------------------------
- 폴더를 노트북에 복사한 뒤, 복사한 폴더의 자동 시작 켜기.bat 을 더블클릭하세요.
  다음에 로그인할 때부터 체험 화면이 저절로 떠요.
- 직접 하려면: Win+R → shell:startup 입력 → 열린 폴더에 시작.bat 의 바로 가기를 넣으세요.
- 그만두려면 자동 시작 끄기.bat 을 더블클릭하세요(또는 그 폴더의 바로 가기를 지우세요).
- USB 에 있는 폴더로 켜 두면, USB 를 빼거나 드라이브 문자가 바뀔 때 자동 시작이 안 돼요.
- 폴더를 다른 곳으로 옮겼다면 자동 시작 켜기.bat 을 다시 눌러 주세요.


6. 하루 종일 돌리기 전에 노트북 설정 (노트북마다 한 번)
-------------------------------------------
- 전원 어댑터를 꽂아 두세요.
- 화면·절전 끄지 않기
  설정 → 시스템 → 전원 및 배터리 → '화면 및 절전' 항목
  → '전원 연결 시' 화면 끄기와 절전 모드를 모두 '안 함'으로. (Windows 판에 따라 이름이 조금 달라요.)
  (검은 창이 떠 있는 동안에는 서버가 화면이 꺼지지 않게 붙잡아 두지만, 설정도 바꿔 두는 게 안전해요.)
- 덮개를 닫아 둘 일이 있으면: 제어판 → 전원 옵션 → '덮개를 닫으면 수행되는 작업' → 전원 사용 '아무것도 안 함'.
- 알림 끄기: 설정 → 시스템 → 알림 → '방해 금지' 켜기 (예전 Windows 에서는 '집중 지원'), 또는 알림 끄기.
- 업데이트로 다시 시작되지 않게: 설정 → Windows 업데이트 → '업데이트 일시 중지'.
- 소리: 헤드폰을 꽂고 Windows 음량을 충분히 올리세요(체험 화면에서도 키보드 음량 키가 먹어요).
  블루투스 헤드폰이면 연결이 끊기지 않았는지 가끔 확인하세요.
- 화면 배율은 Windows 권장값 그대로 두세요. 체험 화면은 15.6·17인치 노트북 전체 화면에 맞췄어요.
- 인터넷(Wi-Fi)은 없어도 돼요. 꺼 두면 업데이트·알림 걱정이 줄어요.
- 노트북 제조사 앱(LG 그램: LG Control Center / 갤럭시북: Samsung Settings)에 화면 자동 꺼짐이나
  절전 기능이 따로 있으면 그것도 꺼 두세요.


7. 문제가 생기면
-------------------------------------------
- '체험 사이트 파일을 찾지 못했어요'  → site 폴더가 빠졌어요. 폴더를 통째로 다시 복사하세요.
- 'Chrome 이나 Edge 를 찾지 못했어요' → 서버는 켜져 있어요. 브라우저에서 아래 체험 주소를 여세요.
- '서버를 켜지 못했어요'             → 노트북을 다시 켠 뒤 시작.bat 을 누르세요.
- 화면에 '연결할 수 없음'이 떠요     → 서버(검은 창)가 꺼졌어요. 시작.bat 을 다시 더블클릭하세요.
- 화면은 뜨는데 소리가 안 나요       → 헤드폰 연결과 Windows 음량을 확인하세요.
- 'server 폴더를 찾지 못했어요'      → zip 을 연 채로 눌렀어요. [모두 압축 풀기] 를 한 뒤 풀린 폴더에서 누르세요.
- '게시자를 확인할 수 없습니다' 창이 떠요 → [실행] 을 누르세요. 한 번 켜지면 다음부터는 안 떠요.
- 파란 'Windows의 PC 보호' 창이 떠요 → [추가 정보] → [실행] 을 누르세요. 한 번 켜지면 다음부터는 안 떠요.
- 백신 프로그램이 막아요             → 이 폴더를 백신의 예외(허용 목록)에 넣으세요.


참고
-------------------------------------------
- 체험 주소: http://localhost:8090/experience/visitor.html
  (8090 이 쓰이고 있으면 8091~8099 중 빈 곳을 써요. 검은 창에 실제 주소가 나와요.)
- 체험 화면은 노트북 안에 따로 만든 브라우저 프로필(%LOCALAPPDATA%\SeeonBooth)로 떠요.
  평소 쓰는 Chrome·Edge 의 로그인·기록과 섞이지 않아요.
- 인터넷이 되면 https://see-on26.github.io/seeon-website/experience/visitor.html 도 같은 체험이에요.
- Edge 로 띄우고 싶으면 명령 프롬프트에서: 시작.bat -Browser edge
