만든 방식

무엇을 말할지보다 언제 말하지 않을지를 먼저 고민했어요

  1. 01

    듣고 봐요

    공유된 화면을 0.4초마다 살피고, 회의 소리를 받아 적어요. 3초 넘게 머문 화면만 새 화면으로 쳐요.

  2. 02

    빈자리 후보를 찾아요

    ‘이 부분’, ‘73%’, ‘많이 올랐죠’, ‘꽤 넓죠’, 자료를 띄우고 말이 멈춘 순간처럼 화면을 봐야 알 수 있는 여섯 가지 신호를 찾아요. 한국어는 형태소 분석으로 찾아서 조사 ‘이’나 ‘저는’의 ‘저’를 가리키는 말로 착각하지 않아요.

  3. 03

    말할지 판단해요

    앞뒤 말만 보고 이미 말로 설명됐는지 따져요. 이 단계에는 화면을 넣지 않아요. 알 수 있거나 애매하면 넘어가요.

  4. 04

    화면에서 근거를 찾아요

    빈자리라고 판단한 것만 화면에서 찾아요. 정해진 칸만 채우고 문장은 프로그램이 조립해요. 숫자는 화면 글자와 다시 맞춰 보고, 화면에 없으면 버려요.

  5. 05

    때를 골라 들려줘요

    직접 물은 질문의 답이 가장 먼저예요. 비슷한 안내를 방금 했거나 너무 늦어진 안내는 버리고, 문장이 끝나는 자리를 골라 넣어요.

회의 내용은 밖으로 보내지 않아요

  • 팀 서버 한 대에서 처리해요

    화면 읽기, 받아쓰기, 판단, 해설, 음성까지 모델 다섯 가지를 시온 팀의 GPU 서버 한 대에서 돌려요. 회의 화면과 말을 외부 AI 서비스로 보내지 않아요.

  • 공유된 화면만 봐요

    회의 창에서 공유 화면 영역만 읽어요. 회의 소리는 파일로 남기지 않고, 일시정지를 누르면 화면 읽기와 해설이 바로 멈춰요.

  • 기록은 내 컴퓨터에만 남아요

    회의 스크립트와 요약은 내 컴퓨터의 문서 폴더에만 저장돼요. 서버와는 앱 전용 보안 연결로만 주고받아요.
