# 시온 STORY 내레이션 — ElevenLabs 로 만들기

일반객 체험 1단계 「시온 STORY」 영상의 내레이션 파일이에요. 지금 들어 있는 `n1.mp3 … n6.mp3` 는 **임시 음성(Microsoft Edge)** 이라, ElevenLabs 로 만든 파일을 **같은 이름으로 이 폴더에 덮어쓰면** 영상이 그대로 그 음성으로 바뀌어요. 줄마다 파일 길이를 재서 화면 전환·자막 시간을 맞추므로 따로 고칠 것은 없어요.

시온 해설(시온 AD) 음성은 여기에 들어가지 않아요(`data/visitor/ad/`, 그대로 둠).

## 만들 파일 (6개, 합쳐서 25~30초)

| 파일 | 화면 | 문장 |
| --- | --- | --- |
| `n1.mp3` | 노트북 화상회의 (영상) | 오늘도 화상회의가 시작됩니다. |
| `n2.mp3` | 차트를 가리키며 발표하는 사람 (영상) | 발표자는 화면을 띄우고 말합니다. "여기를 보시면…" |
| `n3.mp3` | 탁자 앞에 앉은 시각장애인 (영상) | 하지만 화면을 볼 수 없다면, '여기'는 어디일까요? |
| `n4.mp3` | 점자를 읽는 손 (영상) | 시각장애인 열에 아홉은, 놓친 회의 흐름을 다시 따라가기 어렵다고 말합니다. |
| `n5.mp3` | 헤드폰을 쓰고 노트북을 쓰는 사람 (영상) | 그래서 우리는 시온을 만들었습니다. |
| `n6.mp3` | 시온 로고 | 말로 채워지지 않은 화면의 빈자리를, 소리로 채웁니다. |

- 톤: 다큐멘터리 내레이터처럼 차분하고 낮게. 한 줄이 4~7초쯤이 되도록 읽으면 전체가 25~30초예요.
- n2 의 "여기를 보시면…" 은 발표자 말을 옮기는 부분이라 살짝 다른 톤(인용)으로 읽으면 좋아요.
- n4 의 "열에 아홉"은 설문 24명 중 22명(92%)을 말로 옮긴 거예요.
- 형식: mp3 (44.1kHz 권장). 앞뒤 무음은 짧을수록 좋아요(줄 사이 간격은 화면이 0.6초씩 넣어요).

## 웹에서 만들 때

1. ElevenLabs → Text to Speech 에서 목소리를 고르고, 모델은 **Eleven Multilingual v2**(한국어)로 둬요.
2. 위 표의 문장을 한 줄씩 넣어 만들고, 내려받은 파일 이름을 `n1.mp3` … `n6.mp3` 로 바꿔 이 폴더(`src/experience/story/`)에 넣어요.
3. 저장소 루트에서 `python build.py` 로 다시 빌드해요.

## 한꺼번에 만들 때 (API)

```bash
set ELEVENLABS_API_KEY=발급받은_키
set ELEVENLABS_VOICE_ID=고른_목소리_ID
python tools/elevenlabs_story.py
python build.py
```

특정 줄만 다시 만들려면 `python tools/elevenlabs_story.py n2 n4` 처럼 줄 이름을 붙여요. 문장을 바꾸고 싶으면 `story.json` 의 `lines[].say` 를 고친 뒤 다시 만들어요.

ElevenLabs 로 넣은 파일은 임시 음성 도구(`tools/story_tts.py`)가 덮어쓰지 않아요.
